# Dashboard energético de Ecuador 2023–2026

Cuadro de mando interactivo en un solo archivo HTML (`index.html`): generación, mix, demanda, pérdidas, territorio, crisis hídrica del 14-oct-2026 y simulador de punto crítico.

Demo: https://andersoundz.github.io/dashboard-energia-ecuador/

## Uso
Abrir `index.html` en el navegador (requiere internet para cargar Chart.js).

## Fuentes
- ARCONEL: Balance multianual 2015-2024, estadística anual 2023-2025, BNEE julio 2026, cobertura y consumo per cápita.
- BEN 2025 (Ministerio de Ambiente y Energía): proyección de demanda 2025-2028.
- Ecuavisa (14-oct-2026) y prensa: cotas de embalses y déficit.

## Advertencia
Las proyecciones y el simulador son escenarios propios con supuestos editables; no son pronósticos oficiales.
